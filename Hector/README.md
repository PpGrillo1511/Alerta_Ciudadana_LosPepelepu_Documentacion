## 🎯 Objetivo del Proyecto

El propósito de este proyecto es diseñar e implementar  una **plataforma web** para que los ciudadanos puedan **reportar incidentes urbanos** como accidentes, vandalismo, fallas de infraestructura y situaciones de riesgo, generando datos **geolocalizados** que puedan ser analizados para mejorar la toma de decisiones de las autoridades locales.
